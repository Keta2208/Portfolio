Overview

A retail data warehouse built end to end on SQL Server: a star-schema data model, ETL pipelines that load and validate the data, OLAP cubes for slicing it, and parameterized dashboards that support retail decisions.

1fact table
6dimension tables
3layers: ETL, cubes, reports

The architecture

How it was built

  1. Model the data

    A star schema in SQL Server with one fact table and six dimensions, designed for fast analysis of sales.

  2. Load it with SSIS

    SSIS ETL pipelines load, transform, and validate sales, product, and channel data.

  3. Build OLAP cubes

    SSAS cubes make it easy to slice the warehouse by any dimension.

  4. Deliver SSRS dashboards

    Parameterized reports show monthly sales and gross-profit trends, top categories by profit, and channel return rates.

What it supports

  • Retail teams can see how sales and profit move month to month, which categories earn the most, and which channels have the highest return rates.
