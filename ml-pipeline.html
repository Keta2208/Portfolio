The overview

This project, built for IDS 575 at UIC, takes a multi-class classification problem from raw data to a written report. It was completed with a teammate and compares four model families on the same dataset of about 70,000 samples.

The goal was a clean, repeatable pipeline: the same preparation and evaluation steps applied to every model, so the comparison is fair.
