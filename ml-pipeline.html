Overview

A multi-class classification project built for IDS 575. The aim was to compare four different model families on the same prepared dataset of roughly 70,000 samples, so that differences in results come from the models and not from how the data was handled.

~70Ksamples
4model families
1shared pipeline

How it was built

  1. 1

    Prepare one dataset

    The data of about 70,000 samples went through a single preprocessing routine, so every model sees identical inputs.

  2. 2

    Train four model families

    Logistic Regression as a linear baseline, Random Forest as a bagged tree ensemble, LightGBM as gradient boosting, and a multi-layer perceptron (MLP) as a neural network.

  3. 3

    Evaluate them the same way

    The same evaluation steps were applied to every model, which keeps the comparison fair.

  4. 4

    Write it up

    The method and findings are documented in a final report written with a teammate.
